# Файл обязателен для Euler и Linear при exact_solution = formula или fields.
# При off файл не читается. В каждом отчёте нормы появляются в консоли и в sol_error.txt.
#
# Режим fields. Вместо блока формул ниже укажите путь к узловому снимку AEROFIELDS той же сетки:
# path = "../reference/final.fields"
# Путь обязателен. Относительный путь отсчитывается от каталога exact.txt.
# В MPI укажите общий снимок исходной сетки (layout = global).
# Один снимок служит эталоном на всех отчётных шагах, независимо от времени в его заголовке.
# Стандартные скалярные поля rho, ux, p (также uy в 2D/3D, uz в 3D) находятся по имени.
# Если имена отличаются, укажите привязки как в init.txt, например:
# rho = density
# ux = "velocity" x
# Если есть скалярное E, сравнивается сохранённая энергия; иначе она вычисляется из примитивных величин.
# Можно задать другое имя или компоненту энергии: E = energy.
# Для единого консервативного поля вместо скалярных привязок задайте field = U.
# В U нужны именованные компоненты rho, rho_ux, [rho_uy], [rho_uz], E.
#
# Режим formula. Для rho, p и всех активных компонент скорости формулы обязательны.
# Для Linear задайте пульсации относительно linear.txt. Энергию солвер вычисляет сам.
# t — время отчёта, в режиме steady — псевдовремя. Пример переноса со скоростью 0.3:
# rho = 1 + 0.01*cos(2*pi*(x-0.3*t))
# ux = 0.3
# uy = 0
# p = 1
#
# Язык математических формул
# Каждую величину задавайте на своей строке в форме имя = выражение. После # идёт комментарий.
# Имена чувствительны к регистру. Десятичный разделитель — точка: 2, 0.25, .5, 1.2e-3.
# x, y, z — координаты узла в единицах сетки. t — время, в начальном поле t = 0.
# pi и e — константы. Умножение записывайте явно: 2*pi*x. Вызов функции требует скобок.
# В формуле доступны только перечисленные переменные и константы. Каждая строка вычисляется независимо.
#
# Операции перечислены от высшего приоритета к низшему:
#   (выражение), вызов функции
#   ^ или **                 степень, группировка справа: 2^3^2 = 512
#   унарные +, -, !          смена знака и логическое отрицание: -2^2 = -4
#   *, /, %                  умножение, деление, остаток (как fmod)
#   +, -                     сложение, вычитание
#   <, <=, >, >=, ==, !=     сравнения, результат 1 или 0
#   &&                       логическое И
#   ||                       логическое ИЛИ
# Нуль означает ложь. Интервал запишите как x >= 0 && x < 1.
# if(условие, значение_при_истине, значение_при_лжи) вычисляет только выбранную ветвь.
# && и || пропускают правую часть, когда ответ уже известен.
#
# Функции одного аргумента:
#   sin(a), cos(a), tan(a)        тригонометрические функции, углы в радианах
#   asin(a), acos(a), atan(a)     обратные функции, результат в радианах
#   sinh(a), cosh(a), tanh(a)     гиперболические функции
#   exp(a), expm1(a)              e^a и e^a - 1
#   log(a), ln(a)                 натуральный логарифм
#   log2(a), log10(a), log1p(a)   двоичный, десятичный логарифмы и ln(1+a)
#   sqrt(a), cbrt(a), abs(a)      квадратный корень, кубический корень, модуль
#   floor(a), ceil(a), round(a)   округление вниз, вверх и до ближайшего целого
#                                 (при равенстве расстояний round округляет от нуля)
#   erf(a), erfc(a)               функция ошибок и дополнительная функция ошибок
# Функции двух аргументов:
#   atan2(y,x)                    угол в радианах с учётом четверти
#   pow(a,b), hypot(a,b)          a^b и длина вектора (a,b)
#   min(a,b), max(a,b)            меньшее и большее из двух значений
#   fmod(a,b)                     остаток деления со знаком a
#
# Выбранная ветвь должна дать конечное вещественное число. Например, при x = 0
# выражение if(x == 0, 1, sin(x)/x) возвращает 1 и пропускает деление.
