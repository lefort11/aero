# bc.txt — граничные условия
#
# 1. Метки сетки и формат файла
#
# Одна секция назначает условия одной метке сетки или группе меток. Например,
# [wing_upper, wing_lower] задаёт одинаковые условия на обеих сторонах крыла.
# Имя с запятой заключайте в двойные кавычки. Опишите каждую метку ровно один раз.
# Для периодической пары достаточно одной секции. Комментарий начинается с #.
# Имена ключей, правил и столбцов профиля чувствительны к регистру.
#
# Полный пример для круглого сопла (Euler, наружная нормаль на входе направлена против оси x).
# Чтобы использовать его, замените nozzle на метку сетки и снимите # со строк секции.
#
# [nozzle]
# bc_type free
# external = reference_state
# profile = inlet_profile.dat
# profile_center 0 0 0
# profile_axis 1 0 0
# superin p_interior
# inflow  in_char
# outflow base_p initial
#
# Сначала солвер собирает внешнее состояние каждой площадки из reference_state и таблицы.
# Затем выбирает одну из трёх строк по режиму течения на этой площадке.
#   superin p_interior   Плотность и вся скорость берутся из подготовленного внешнего
#                        состояния, включая данные профиля. Давление берётся из области.
#   inflow in_char       Входящие характеристики берутся из внешнего состояния,
#                        выходящая — из области. Давление на площадке может отличаться
#                        от табличного даже при наличии столбца p.
#   outflow base_p initial   Давление берётся из начального поля у этой площадки.
#                        Плотность и нормальная скорость вычисляются по внутренней
#                        энтропии и выходящей характеристике; касательная скорость внутренняя.
# Строки p_interior и in_char записываются без аргументов. Источник и файл уже заданы в секции.
#
# 2. Как собрать внешнее состояние
#
# external = reference_state   Основа — опорное состояние (по умолчанию).
# external = initial           Основа — начальное поле у площадки, при --recover берётся исходное поле.
# external = interior          Основа — текущее состояние узла со стороны области.
#
# Без профиля внешнее состояние равно основе. С профилем заданные столбцы заменяют
# соответствующие компоненты основы. Например, при external = initial и таблице R_yz u_x
# осевая скорость берётся из таблицы, а плотность и давление — из начального поля.
# При external = interior недостающие величины обновляются на каждой стадии расчёта.
#
# Опорное состояние можно задать прямо в секции. Например, для двумерной сетки:
# reference_state rho=1 p=1 ux=2 uy=0
# В 1D укажите ux, в 2D — ux и uy, в 3D — ux, uy и uz. Для Euler нужны rho > 0 и p > 0.
# Если единственное правило, использующее опорный газ, — p_interior, p можно опустить.
# Вместо rho можно задать T при заданном p. Для Euler T означает T/T_amb:
# reference_state T=1 p=2.857142857142857 ux=1 uy=0
# Солвер вычисляет rho = gamma*mach^2*p/T. Для этого в gas.txt обязателен mach > 0.
#
# Если строка reference_state отсутствует и нужна опорная величина, солвер использует gas.txt.
# Для Euler при gamma > 1 и mach > 0 получаем rho=1, |u|=1, c=1/mach и p=1/(gamma*mach^2).
# Направление задают углы phi (от +x к +y) и theta (от плоскости xy к +z), оба в градусах.
# По умолчанию phi=theta=0 и поток направлен вдоль +x. В 1D и 2D задайте theta=0.
# В 3D допустимы углы theta от -90° до 90°, в 1D угол phi должен быть кратен 180°.
# Углы опорного потока читаются из gas.txt, а углы начального потока freestream — из init.txt.
#
# 3. Таблица профиля (Euler)
#
# profile = inlet_profile.dat   Путь отсчитывается от каталога bc.txt.
# profile_center 0 0 0          Точка на оси, по умолчанию начало координат.
# profile_axis 1 0 0            Направление оси, по умолчанию вдоль +x.
#
# Пример содержимого inlet_profile.dat:
# R_yz  ro   u_x   u_r   p    nutilde
# 0.00  1.0  2.00  0.00  1.0  0.00001
# 0.25  1.0  1.90  0.02  1.0  0.00002
# 0.50  1.0  0.10  0.00  1.0  0.00000
#
# R_yz — неотрицательное расстояние до оси. Столбцы ro и p задают плотность и давление.
# u_x направлена вдоль profile_axis, u_r — от оси. nutilde — рабочая вязкость SA.
# При наличии этих столбцов требуется ro > 0, p > 0 и nutilde >= 0.
# Обязательны R_yz и хотя бы один столбец данных. Порядок столбцов задаёт заголовок.
# Радиус строго возрастает. Между строками используется линейная интерполяция,
# за пределами таблицы — ближайшая строка. На оси радиальная скорость равна нулю для полного профиля.
#
# Сокращённые записи (выберите одну вместо пары external и profile):
# profile_ref inlet_profile.dat       Пропуски заполняются из reference_state.
# profile_init inlet_profile.dat      Пропуски заполняются из начального поля.
# profile_interior inlet_profile.dat  Пропуски заполняются из текущего внутреннего поля.
# При полном наборе столбцов все три записи дают одинаковые данные. Если отсутствует
# nutilde, для profile_ref используется набегающее значение SA, для остальных — выбранное поле SA.
#
# 4. Правила для bc_type free
#
# superin, inflow и outflow обязательны. Нормаль n направлена наружу, u_n = u·n.
# Для обычной границы u_n и скорость звука c берутся изнутри. При u_n <= -c действует
# superin, при -c < u_n < 0 — inflow, при 0 <= u_n < c — outflow. Сверхзвуковой выход
# при u_n >= c переносит внутреннее состояние. Отдельная строка superout не требуется.
# С табличным профилем для выбора режима используются средние величины Роу.
# Особый случай superin external: если u_ext·n <= -c_ext, сразу подаётся всё внешнее
# состояние. Это позволяет запустить сверхзвуковую струю из покоя внутри области.
#
# external       В любом из трёх режимов задаёт плотность, давление и всю скорость извне.
#                Запись reference_state на месте имени правила эквивалентна external.
# p_interior     В любом из трёх режимов задаёт плотность и скорость извне, давление изнутри.
# in_char        Только для inflow. В 3D входят четыре характеристики: из внешнего газа
#                берутся энтропия (p/rho^gamma), две касательные скорости и J- = u_n - 2c/(gamma-1).
#                J+ = u_n + 2c/(gamma-1) берётся из области. В 2D касательная компонента одна,
#                в 1D их нет. Солвер восстанавливает граничные u_n, c, rho и p по этим данным.
#
# Для inflow и outflow можно задать одну величину:
#   base_p     статическое давление;
#   base_u     скорость вдоль наружной нормали (на входе обычно отрицательна);
#   base_rho   плотность.
# Без аргумента всё состояние остаётся внутренним. Число задаёт постоянную величину;
# initial берёт выбранную величину из начального поля. Остальные величины получаются
# с сохранением внутренней энтропии, касательной скорости и исходящего J+.
# Примеры: inflow base_u -0.3, outflow base_p 1.0, outflow base_p initial.
# outflow base_p external задаёт давление из подготовленного внешнего состояния.
#
# Другие варианты superin: строка superin без аргументов берёт внутреннее состояние,
# superin initial — начальное. Отдельные компоненты можно заменить, например:
# superin initial rho=1.2 p=1 ux=2
# Поддерживается и прежняя запись для сопла: superin profile, inflow profile,
# outflow base_p profile (каждое правило на отдельной строке).
#
# При Equations = Linear режим выбирается по фоновому потоку. Явные значения rho, p и
# скорости задают пульсации, T — пульсацию T/T_amb. При автоматическом reference_state
# пульсации равны разности набегающего состояния и фона. Табличный профиль доступен только в Euler.
# Для inflow in_char в Linear выходящая величина u'_n + p'/(rho0*c0) берётся из области.
# Здесь штрих обозначает пульсацию, rho0 и c0 — плотность и скорость звука фонового потока.
#
# 5. Стенки, периодика и рабочие примеры секций
#
# adiabatic_wall — неподвижная теплоизолированная стенка с прилипанием (также допустимо wall).
# В вязком расчёте скорость на стенке и поток тепла через неё равны нулю; при SA nu_tilde=0.
# novisc_wall — теплоизолированная стенка со скольжением: нормальная скорость равна нулю,
# касательная свободна. Внешние вязкое трение, поток тепла и поток SA через стенку равны нулю.
# Для стенок достаточно bc_type. На free внешний вязкий поток равен нулю.
[ymin]
bc_type adiabatic_wall

[ymax]
bc_type free
superin initial
inflow  base_p
outflow base_u

# В periodic обязательны pair и translation. Вектор переноса ведёт от узлов первой
# метки к соответствующим узлам второй. В примере длина периода по x равна 1.
# Для xmax отдельную секцию создавать не нужно.
[xmin]
bc_type periodic
pair xmax
translation 1 0 0
