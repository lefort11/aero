# Общие средства unit-тестов

В `mesh_fixture.h` собраны генераторы ориентированных ячеек и небольших контрольных сеток для mesh, CV, периодических границ, начального поля, файлов полей и Tecplot. Функции возвращают собственный `MeshData`, поэтому тест может изменить патч или связность локальной копии.

В `test_suite.h` находятся регистрация проверки, выполнение именованного набора и проверка типа исключения с необязательным фрагментом сообщения. Каждый исполняемый файл хранит свой реестр и возвращает код 1 при падении хотя бы одной проверки.

В `test_checks.h` находятся базовые проверки условия и аргумента обязательного GPU. Тестовые ядра и их типы данных объявлены в `device_cases.h`, управление временными буферами устройства описано в `device_test_buffer.h`.

В `test_files.h` определён владелец временного файла в рабочем каталоге тестов и операция замены первого фрагмента текстовой заготовки. Имена с пробелами и символом решётки входят в проверки начальных данных.
