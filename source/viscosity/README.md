# Вязкий пространственный оператор

Модуль добавляет в уравнения газа вязкие напряжения и тепловой поток, вычисляет вклад диффузии в ограничение шага и предоставляет производные для неявной матрицы. Закон молекулярной вязкости выбирают в `main.txt`, а число Рейнольдса, число Прандтля и параметры температурного закона задают в [gas.txt](../../templates/gas.txt).

`Aes` подготавливает элементную геометрию и связывает рабочие поля с `viscosity::Operator`. Оператор переводит консервативное состояние в газовые величины, вычисляет коэффициенты переноса и собирает элементные вклады в узловые строки. Файлы `grad.*`, `affine_hex.*` и `volume_coordinates.h` описывают метрики, в том числе специализированное представление аффинных гексаэдров и вычисление по координатам вершин.

`JacobianPattern` задаёт структуру вязких связей, а `Jacobian` вычисляет коэффициенты блоков. При `compact_jacobian = on` матрица использует только пары узлов, соединённых ребром. Полная вязкая невязка по-прежнему использует элементный шаблон. [Модуль турбулентности](../turbulence/README.md) предоставляет добавочную вязкость и использует общую геометрию.

Проверки геометрии, потоков и производных запускаются через `make viscosity-test`, расчётные задачи через `make viscosity-qa`.
