# Неявный шаг газа

`BdfStep` продвигает консервативное поле по BDF1 или BDF2 и выполняет неявный псевдошаг в режиме steady. Для BDF2 он хранит предыдущий принятый слой и длительность шага. При запуске без истории первый шаг выполняется по BDF1. При продолжении расчёта история восстанавливается из контрольной точки.

На каждой поправке Ньютона пространственный оператор пересчитывает потоки выбранной реконструкции. `SpatialJacobian` строит блочный якобиан с конвективным потоком первого порядка и, при включённой вязкости, добавляет вязкие производные. `BdfLinearSystem` учитывает временную диагональ и решает систему для поправки методом BiCGSTAB. Параметры `solver_tol` и `newton_tol` относятся соответственно к линейной системе и невязке полного неявного шага. Норма для остановки steady проверяется отдельно.

Предобусловливатель BJ использует только диагональные блоки. CSGS выполняет прямой и обратный проходы по цветам строк. `Partition` описывает собственные строки и операции обмена. `Workspace` и `KrylovScratch` размещают векторы на выбранном исполнителе. Время жизни общих буферов учитывают также при [грубой коррекции](../multigrid/README.md).

При общем шаге газа параметр `predictor_history_order` задаёт максимальную степень экстраполяции по принятым слоям. Значение 0 отключает её. Веса учитывают фактические интервалы времени. Решатель оценивает пробу по полной невязке BDF и восстанавливает исходное поле, если новая норма составляет 80% исходной или больше. Предыдущие слои хранятся в уже выделенных векторах BiCGSTAB. После линейного решения или перезапуска история предиктора набирается заново. При BDF1 подстановка может использовать демпфирование для медленно затухающих поправок.

В steady, BDF1 и BDF2 газовый блок использует фиксированную рабочую вязкость. Затем SA решает скалярное уравнение при обновлённом газовом поле методом Ньютона с BiCGSTAB. На каждой проверке полной невязки конвекция SA использует выбранную реконструкцию. Для матрицы поправки скалярный противопоточный поток определяется ориентированным массовым расходом. Параметры допуска, пределы итераций и выбор BJ или CSGS читаются из настроек неявного решателя.

Проверка критерия steady на принятом слое оставляет его подписанный баланс в рабочем векторе Ньютона. Следующий совместный шаг газа и SA может прочитать готовую начальную правую часть. При смене потоков или использовании вектора для отчёта решатель собирает её заново.

`newton_max_iter` задаёт число доступных линейных поправок Ньютона. При стандартном `newton_without_predictor = off` решатель проверяет предиктор перед этими поправками даже при лимите 1. Если пробное поле удовлетворяет допуску, в отчёте будет ноль поправок. При `newton_without_predictor = on` газ начинает с принятого слоя: временная подстановка, экстраполяция истории, предобусловленный и совместный предикторы пропускаются. Уравнение SA и критерии принятия шага продолжают действовать.

Настройки сборки матрицы, предобусловливателя, локального шага и критериев остановки приведены в [implicit.txt](../../templates/implicit.txt). Модульные проверки запускаются командой `make implicit-test`.

В `local_gas_prediction.h` описана дополнительная узловая подстановка для двумерного характеристического WENO или MP5 на одном разделе. `prediction_execution.h` отбирает площадки активных узлов на CPU или GPU и размещает список в рабочей памяти поправки. Когда исходный баланс выше допуска только в небольшой части области, подстановка пересчитывает потоки примыкающих граней этих узлов. Все узлы читают одно приближение. После записи поправок решатель пересчитывает конвекцию, вязкие потоки и SA на всей сетке. На старте с CFL выше единицы исходную попытку и её повторы ведёт обычный связанный решатель.

Если для локального шага уже собран предобусловливатель, пространственный предиктор делает одну пробную подстановку. При недостаточном снижении полной невязки решатель использует ту же матрицу для первой линейной поправки Ньютона.

### Обход строк на CPU и GPU

В `row_execution.h` находится `apply_rows`. Тип операции определяет точку входа для предиктора истории, обновления Ньютона, BiCGSTAB и переноса или обновления многосеточного вектора. На хосте сохраняется порог последовательного обхода `parallel_for`. На устройстве остаётся один запуск Kokkos с прежними параметрами. `Partition::maximum_norm` согласует ошибки локальной работы перед общей редукцией нормы. Импорт и экспорт BDF2 используют одни смещения компактного и полного поля истории.

`measure_rows` запускает совмещённое обновление и вычисление локальной нормы Ньютона или BiCGSTAB. Оба пути используют общее согласование максимума и ошибок в `Partition::maximum_norm`.

`matrix_execution.h` собирает и умножает блочные строки, обновляет временную диагональ, факторизует и применяет Якоби. На GPU соседние дорожки могут считать разные уравнения одной строки. На CPU все уравнения строки обрабатываются вместе. Упаковка и произведение CSGS используют фактическую ширину раскладки.

## Демпфирование нелинейных поправок газа

При `solver_damp_correction = on` предиктор и Ньютон используют общий с SA двухчленный фильтр из `source/timestep/correction_filter.h`. Он действует в steady, BDF1 и BDF2 для любой реконструкции. Когда после газовой поправки остаётся больше половины предыдущей полной нормы, фильтр принимает 0,65 текущей поправки за вычетом 0,15 предыдущего принятого изменения. При первой демпфированной пробе история равна нулю. Предиктор также может сразу проверить демпфированную пробу после неудачной полной подстановки. Сходимость определяет заново вычисленная невязка принятого поля.

Предиктор получает историю из разности текущего поля и уже имеющегося поля отката. В Ньютоне вектор последней поправки хранит сдвиг начального приближения Крылова. При сдвиге x₀ решается линейная система A·x = b + A·x₀ с начальным полем x₀. Её начальная невязка равна b, поэтому используются обычный допуск BiCGSTAB и существующие рабочие векторы. Необязательный параметр по умолчанию выключен. Для SA фильтр действует независимо от газовой опции.
