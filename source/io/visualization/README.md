# Визуализация полей

Решатель и утилита `visfield` используют общие писатели Tecplot PLT v112 и VTK Legacy 4.2.
Оба формата содержат геометрию в координатах сетки и поля двойной точности.

## Запись по зонам

```ini
[pressure]
file = pressure.fields
every_steps = 10
multi = 1
variables = p
visualization = tecplot, vtk
```

На шаге 10 зона запишет `pressure_000010.fields`, `pressure_000010.plt` и `pressure_000010.vtk`.
Каждое имя формата можно указать отдельно. Параметр `format` управляет кодировкой AEROFIELDS.
Срез выводится в нумерации своей подсетки. Стеночный снимок Cp представлен облаком точек с исходными номерами узлов.

## Устройство модуля

- `zone_files.cpp` передаёт всем писателям один набор вычисленных значений. Сначала каждый файл полностью записывается во временный путь рядом с назначением. Затем публикуются представления и основной снимок. Каждый файл заменяется атомарно. В режиме серии конфликт имени отменяет публикацию файлов этой попытки.
- `tecplot.cpp` пишет координаты и поля блоками, сохраняет время и атрибуты переменных. Для рёбер и граней использует отдельные зоны.
- `vtk.cpp` пишет сетку UNSTRUCTURED_GRID. Отрезки, многоугольники и многогранники сохраняют исходную связность. Порядок обхода контура и ориентация каждой грани берутся из сетки. Бинарные массивы используют big-endian. Код хранит буфер на 64 КиБ и рабочий массив для одного контура. Индексы и размер блока CELLS ограничены INT32_MAX.
- `binary_columns.h` читает выбранные узловые поля общего MPI-снимка блоками по 64 КиБ. Ранг 0 хранит полную геометрию только для общей объёмной визуализации. Для локального вывода используются сетки разделов.

Внешний снимок `visfield` сверяет с сеткой по размерности, количествам сущностей и SHA-256. Для записи из решателя геометрия связана со снимком при подготовке зоны. Подробности командной строки приведены в [README утилиты](../../../utils/visfield/README.txt).
