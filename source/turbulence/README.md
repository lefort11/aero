# Турбулентная вязкость и перенос SA

При `Turbulence = On` солвер читает [turbulence.txt](../../templates/turbulence.txt). Для RANS и DDES с `rans_eq = SA` он интегрирует узловую рабочую вязкость `nu_tilde`. Для LES подсеточная вязкость вычисляется по полю скорости и масштабу фильтра. В DDES сеточный масштаб участвует в ограничении длины модели SA в зависимости от расстояния до стенки.

`Storage` владеет полями и рабочими буферами, а `View` передаёт их вычислительным ядрам. `wall.cpp` определяет расстояния по физическим стенкам. `convection.h` использует массовый поток газа для выбора направления переноса. При высоком порядке шаблон газа применяется к полю SA с его собственными весами. Геометрия диффузии строится на тех же элементах, что и [вязкий оператор газа](../viscosity/README.md).

`transport.h` объединяет конвекцию, диффузию и источники при обновлении рабочего поля. `sigma.h`, `nodal_filter.h` и `ddes.h` содержат вычисления модели и масштаба фильтра. Для старта DDES с контрольной точки RANS пример приведён в [init.txt](../../templates/init.txt).

Команда `make turbulence-test` проверяет формулы модели. `make turbulence-qa` запускает расчётные проверки, включая конвективный перенос SA.
