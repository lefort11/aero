# Грубая коррекция стационарного решения

При `time_scheme = steady` в `main.txt` и `steady_multigrid = on` в `implicit.txt` решатель пытается дополнительно уменьшить пространственную невязку после обычного принятого псевдошага. Коррекция меняет газовое поле. При включённом SA проверка пробного поля учитывает также невязку переноса рабочей вязкости.

* `Aggregates` строит один грубый уровень. Свободный собственный узел объединяется с ещё свободными соседями, начиная с наибольшей общей площади, до двух узлов в 1D, четырёх в 2D и восьми в 3D. Граница MPI-раздела ограничивает состав агрегата. Умножение мелкосеточной матрицы на вектор сохраняет связи с соседними процессами.
* `Transfer` суммирует интегральные невязки собственных узлов и продолжает постоянную поправку на узлы агрегата. Поправка к закреплённым компонентам импульса на стенке равна нулю. При умножении на якобиан из результата вычитается временная диагональ с теми же объёмами и узловыми шагами, что при сборке.
* `CoarseStep` сначала проверяет направление последнего принятого изменения поля. Множитель определяется методом наименьших квадратов по агрегатам и ограничен диапазоном от 0 до 2. Если это направление не принято, короткая итерация GCR решает грубую систему с оператором `PᵀJP`. Затем BJ или CSGS сглаживает оставшийся дефект на мелком уровне.

Для каждого направления солвер пробует до четырёх множителей, при отказе уменьшая множитель вдвое. Он принимает допустимое поле со строго меньшей конечной нормой. Строка `Steady multigrid` в журнале указывает результат, масштаб и направление (`last step` или `aggregates`). При отклонении всех проб расчёт продолжается с поля обычного псевдошага.

Отдельный `ScalarSmoother` вычисляет коэффициенты итераций Чебышёва для скалярного уравнения SA. Индексы агрегатов и рабочие массивы основной коррекции учитываются при планировании памяти. Векторы GCR используют свободное место BiCGSTAB, когда его достаточно.

Проверки операторов переноса и принятия поправки входят в `make implicit-test`. Сценарий `make steady-multigrid-qa` проверяет коррекцию при запуске солвера. Настройки описаны в [шаблоне implicit.txt](../../templates/implicit.txt).
