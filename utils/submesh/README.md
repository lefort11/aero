# Срез сетки плоскостью

Утилита `mesh_slice` строит двумерную поверхность внутри трёхмерной сетки или линию внутри двумерной. Принимает обычную сетку Aero и архив разделов `.mdec`. Архив при подготовке среза читается целиком в одном процессе. Для сборки утилит используйте `make mesh_slice tecplot`.

```sh
mesh_slice grid.mesh slice.submesh faces 0 0 1 0.5
mesh_slice grid.mdec oblique.submesh cut 1 1 0 0.35
```

Последние четыре числа задают плоскость `nx*x + ny*y + nz*z = offset`. В первом примере это `z = 0.5`, во втором — `x + y = 0.35`. После них можно указать абсолютный допуск расстояния до плоскости в единицах сетки. По умолчанию это 64 машинных эпсилон, умноженных на масштаб координат и смещения плоскости.

- `faces` выбирает грани, у которых все вершины лежат в плоскости с заданным допуском. Общая грань соседних ячеек входит в срез один раз.
- `cut` также пересекает рёбра и соединяет отрезки в элементы среза. Вершина, попавшая в допуск, сохраняет исходные координаты. Вырожденное пересечение с неоднозначной связностью может потребовать смещения плоскости.

Файл `.submesh` содержит отпечаток исходной сетки, таблицу соответствия, координаты и связность. В каждой строке таблицы записаны номера узлов `a b` (с нуля) и вес `w`. Исходная вершина имеет `a = b` и `w = 0`. Для новой точки солвер записывает значение `(1-w)*f[a] + w*f[b]` отдельно для каждой заказанной переменной.

Поместите файл среза во входной каталог и добавьте зону в `output.txt`:

```ini
[section]
submesh = slice.submesh
file = slice.fields
variables = primary, schlieren
every_steps = 100
multi = 0
```

Нумерация подсетки едина для последовательного и MPI-расчёта. Расписание и финальный снимок работают как у других зон. Для просмотра результата или одной геометрии:

```sh
fields_to_tecplot INPUT/slice.submesh OUTPUT/slice.fields slice.plt
fields_to_tecplot INPUT/slice.submesh geometry.plt
```
